# نوتیفای — مدیریت یادداشت‌ها و وظایف

پیاده‌سازی محلی طرح PDF با Vue 3، Vite، Express و Redis. داده‌ها به حساب کاربری واردشده اختصاص دارند و در Redis نگهداری می‌شوند.

## پیش‌نیازها

- Node.js 18 یا جدیدتر
- npm
- Redis 6 یا جدیدتر که روی همین دستگاه اجرا شود

## اجرا

1. Redis را اجرا کنید. برای نمونه در لینوکس:

   ```sh
   sudo systemctl start redis
   redis-cli ping
   ```

   پاسخ سالم `PONG` است. در صورت استفاده از Redis دیگر، مقدار `REDIS_URL` را در `backend/.env` تنظیم کنید.

2. فایل تنظیمات محلی را بسازید و وابستگی‌ها را نصب کنید:

   ```sh
   cp backend/.env.example backend/.env
   npm install
   ```

3. برای اجرای API و رابط کاربری با هم:

   ```sh
   npm run dev
   ```

   رابط کاربری در `http://localhost:5173` و API در `http://localhost:3000` در دسترس است. Vite درخواست‌های `/api` را به Express هدایت می‌کند. با `Ctrl+C` هر دو سرویس متوقف می‌شوند.

4. برای ساخت نسخهٔ تولیدی رابط کاربری یا اجرای آزمون‌های API:

   ```sh
   npm run build
   npm test
   ```

## API و ذخیره‌سازی

- `GET /api/health` — وضعیت API و اتصال Redis
- `POST /api/auth/register` — ایجاد حساب
- `POST /api/auth/login` — ورود با نام کاربری و گذرواژه
- `GET /api/auth/me` — دریافت حساب واردشده
- `GET /api/notes` و `GET /api/notes/:id` — فهرست و دریافت یادداشت
- `POST /api/notes`, `PATCH /api/notes/:id`, `DELETE /api/notes/:id` — ایجاد، ویرایش و حذف

کلیدهای Redis:

- `notify:user:<uuid>`: اطلاعات کاربر و هش گذرواژه
- `notify:users`: مجموعهٔ شناسه‌های کاربران
- `notify:username:<lowercase-username>` و `notify:email:<lowercase-email>`: نمایه‌های یکتای کاربر
- `notify:note:<uuid>`: یادداشت سریال‌شده
- `notify:user:<uuid>:notes`: مجموعهٔ شناسه‌های یادداشت همان کاربر

گذرواژه‌ها با bcrypt هش می‌شوند. مالکیت یادداشت از شناسهٔ کاربر داخل توکن امضاشده استخراج می‌شود، نه از مقادیر ارسالی مرورگر. کلید JWT پیش‌فرض صرفاً برای توسعهٔ محلی است؛ پیش از استفادهٔ خارج از این محیط، `JWT_SECRET` قوی و خصوصی را در `backend/.env` تنظیم کنید.

## عیب‌یابی

- اگر API در دسترس نیست، `redis-cli ping` و مقدار `REDIS_URL` را بررسی کنید. API در صورت قطع Redis خطای `503` با پیام قابل‌فهم برمی‌گرداند.
- اگر پورت‌ها اشغال‌اند، `PORT` در `backend/.env` یا پورت Vite را تغییر دهید.
- برای خطای توکن یا نشست منقضی‌شده، دوباره وارد حساب شوید.
- نشست «مرا به خاطر بسپار» در فضای ذخیره‌سازی پایدار مرورگر می‌ماند؛ در غیر این صورت فقط تا پایان همان نشست مرورگر.

## محدودیت‌ها

بازیابی گذرواژه در طرح به‌صورت لینک دیده می‌شود اما سرویس ارسال ایمیل یا بازیابی در این پروژهٔ محلی تعریف نشده است؛ رابط کاربری این محدودیت را اعلام می‌کند. این برنامه برای توسعهٔ محلی است و دربرگیرندهٔ مدیریت نشست/توزیع امن کلید در محیط تولید نیست.
